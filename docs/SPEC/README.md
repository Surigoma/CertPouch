# CertPouch 詳細仕様書

## 位置付け

本書は[原仕様](../../SPEC.md)を実装・検証可能な単位へ展開した設計ドラフトである。対象読者は実装者、レビュー担当者、Linux運用担当者とする。原仕様は変更していない。

配布、DNS連携、既存CAを使う更新の実装範囲は[引き継ぎメモ](../HANDOFF.md)を参照する。導入前の確認は[リリースと運用受け入れ](../release-and-acceptance.md)、DNS台帳を使う配布認可は[設定手順](../dns-inventory.md)を参照する。

### 記述の扱い

- **要件**：原仕様に記載された必須条件。
- **詳細化案**：原仕様にない具体的な形式・既定値・手順。本詳細仕様での提案であり、採用前に実装レビューで確認する。
- **未決**：資料不足や環境依存のため判断を残す事項。

各文書の「詳細化案」節は、その節全体を提案として扱う。要件と衝突する場合は原仕様の必須条件を維持し、矛盾を解消してから実装する。

## 共通用語

| 用語 | 意味 |
| --- | --- |
| 証明書名 | 認可と設定に用いる論理識別子。SANそのものとは区別する |
| クライアントID | 証明書を受け取るホストの認証主体 |
| バージョン | 証明書・チェーン・秘密鍵を一組として識別する不変の世代 |
| フィンガープリント | リーフ証明書DERのSHA-256値（詳細化案） |
| 公開 | 検証済み世代をサーバーの配布対象にする操作 |
| 配置 | クライアントで検証済み世代をサービスの参照先にする操作 |

Phase 1は既存証明書の配布に限定する。DNS管理と証明書発行は後続フェーズとし、詳細仕様の存在だけで全フェーズの実装を開始しない。
